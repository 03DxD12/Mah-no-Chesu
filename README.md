# Mahō no Chesu

## Elemental Chess

**Master the Board. Command the Elements.**

Mahō no Chesu is a fantasy-inspired browser chess game where traditional chess strategy is enhanced with elemental attack animations, magical effects, and cinematic captures.

## Features

- Full Traditional Chess Rules
- Elemental Capture Animations
- Check and Checkmate Detection
- Castling
- En Passant
- Pawn Promotion
- Threefold Repetition
- Fifty-Move Rule
- Insufficient Material Detection
- Move History
- Standard Algebraic Notation
- Captured Pieces
- Board Flip
- Player vs Player
- Player vs Computer
- Responsive Design
- Keyboard Support
- Accessibility Settings
- Reduced Motion Support
- GitHub Pages Compatible

## Running Locally

Open `index.html` in a supported browser or serve using any static web server:

```bash
npx serve .
# or
python -m http.server 8000
```

## GitHub Pages

Upload the project to a GitHub repository.

Keep `index.html` in the repository root.

Then enable GitHub Pages under:

Settings → Pages

Choose:

Deploy from a branch

Branch:

main

Folder:

/ (root)
