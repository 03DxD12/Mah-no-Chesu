# Superpowers

Enforce disciplined planning and test-driven verification on complex changes:
1. Write a concise plan covering architecture, edge cases, and failure modes before editing.
2. Reproduce bugs or define failing checks first whenever feasible.
3. Verify every change with actual command/test runs after the final edit.
