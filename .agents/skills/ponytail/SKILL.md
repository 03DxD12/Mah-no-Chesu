# Ponytail (Full Mode)

Keep implementations lean, surgical, and reliable:
1. Prefer minimal diffs and native browser/language APIs over new dependencies or wrappers.
2. Reuse existing project helpers and patterns.
3. Preserve all validation, error handling, and security checks without leaving placeholders or dead code.
