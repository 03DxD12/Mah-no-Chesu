# Understand Anything

Map unfamiliar modules and trace dependencies before editing shared core files:
1. Locate entry points, state owners, and call sites using targeted search.
2. Read only the relevant symbol ranges rather than whole large files.
3. Identify shared invariants, side effects, and callers before proposing changes.
