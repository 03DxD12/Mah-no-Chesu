# Grill With Docs

Before implementing ambiguous features:
1. Ask concise, numbered questions with a recommended default for each open decision.
2. Sharpen domain terminology and record key constraints in docs (`GLOSSARY.md` or ADRs) when needed.
3. Confirm scope and acceptance criteria before writing code.
