# Web Design Guidelines

Audit modified frontend files before completion:
1. Verify keyboard navigation, visible `:focus-visible` rings, and semantic HTML (`button`, `nav`, `dialog`).
2. Ensure accessible labels (`aria-label`, `aria-current`, `aria-live`, `role="dialog"`, `aria-modal="true"`).
3. Allow mobile pinch-zoom (`user-scalable` not disabled) and verify sufficient contrast.
